## The word

> finepause (n.) — the pause before you say "I'm fine" when you're not.

Someone asks how you are, and before the automatic "I'm fine" comes out
there is a tiny held breath — the split second in which you decide not to
tell the truth. English has words for hesitation and for small talk, but
none for that exact beat, where honesty quietly loses to politeness.
"Finepause" is built from two plain English words, so it sounds like
something the language could have grown on its own, and it is short
enough to slip into the very sentence it describes.
